# Angry Birds Remastered (超清重制物理弹弓网页版)

经典《愤怒的小鸟》(Angry Birds) HTML5 Canvas 物理重制版。基于 **Matter.js 2D 刚体物理引擎**、**原生 Web Audio API 程序化音效合成器** 与 **高帧率卡通渲染管线** 开发，纯原生零外部音频/网络依赖。

---

## 🌟 核心特色与原版手感还原

1. **精准抛物线与全射程弹道引导 (Sling Scope)**:
   - 拖拽弹弓即时计算全射程抛物线，计算精度与物理引擎误差小于 0.001px。
   - 具备高辨识度卡通描边交替大小轨迹点、碰撞区域检测与**动态落点十字准星**。
   - 保留前一发动能参考轨迹，支持拉回弹弓中心安全取消发射。

2. **经典六大鸟种与原版特性**:
   - 🔴 **怒红鸟 (Red)**: 经典全能主力，纯物理冲撞击垮承重柱（无主动点击技能）。
   - ⚡ **飞镖黄 (Chuck)**: **木质建筑克星（3.8倍破坏力）**，空中点击激活超音速直线冲刺贯穿木墙。
   - 🔵 **蓝弟弟 (The Blues)**: **冰块与玻璃克星（3.8倍破坏力）**，空中点击一分为三分裂破冰。
   - 💣 **炸弹黑 (Bomb)**: **花岗岩堡垒克星**，重型铁壳撞击，受撞延时引爆或空中点击即时引爆冲击波。
   - 🥚 **白公主 (Matilda)**: 高空战术反向轰炸，空中点击垂直投下高爆爆炸蛋，本体火箭拉升追击。
   - 🌋 **泰伦斯 (Terence)**: 全材质碾压巨无霸，以绝对超重吨位直接碾碎连环防御。

3. **三种材质深度破坏与物理交互**:
   - **木材 (Wood)**: 真实木纹韧性，破损崩散木刺碎片。
   - **冰块/玻璃 (Glass)**: 晶莹透光，受到蓝鸟撞击瞬间粉碎。
   - **花岗石 (Stone)**: 沉实致密，可作为承重地基或摆钟铁球。
   - **TNT 炸药桶**: 受到高速撞击引发链式殉爆。
   - **弹跳垫 (Bouncy Pad)**: 经典橡胶折射，支持战术反弹奇袭。

4. **灵动绿猪 AI 与动态微表情**:
   - 头部眼珠实时转动追踪来袭小鸟。
   - 遭受威胁时流汗颤抖，受伤具备黑眼圈、创可贴等战损表现。
   - 包含普通猪、小猪、钢盔猪（击碎掉落头盔）、胡子领班猪与头戴金冠的国王猪 BOSS。

5. **五大世界 75 大精雕细琢关卡**:
   - 第一章：翠绿牧场 (Poached Eggs)
   - 第二章：落日峡谷 (Mighty Hoax)
   - 第三章：冰峰极境 (Danger Above)
   - 第四章：暗夜王城 (King's Citadel)
   - 第五章：炽热熔岩 (Magma Vault)

6. **纯原生合成音效系统 (Zero-Dependency Web Audio)**:
   - 皮筋拉伸变调、发射破空音、鸟种音效、木石玻璃不同材质撞击声、猪叫声、爆炸重低音与胜利号角。

## 🎮 操作指南

| 操作 | 对应动作 |
| :--- | :--- |
| **拖拽小鸟** | 鼠标左键或触屏按住弹弓上的小鸟向后拉伸瞄准 |
| **取消发射** | 将小鸟拉回弹弓中心或向前轻推即可安全取消，不消耗弹药 |
| **释放技能** | 小鸟空中飞行途中**点击屏幕任意位置**或按 **空格键 (Space)** |
| **快速重玩** | 点击右上角重玩按钮或按键盘 **R** 键 |
| **章节选关** | 点击顶部 **🗺️ 选关** 随时切换 75 大关卡 |

## 🚀 本地运行

无需配置任何前端构建工具（如 Webpack/Vite），下载解压后即可直接畅玩：

### 方式 1：双击直接运行
直接双击打开目录下的 `index.html` 或 `run.bat`。

### 方式 2：Python 简易服务器
```bash
python run_game.py
```
终端将自动启动 HTTP 服务并在浏览器中打开 `http://localhost:8000/index.html`。
